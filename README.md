## 👨‍💻 About Me

Hi! I'm **Amal Ablakulov** — a Computer Vision & Full-Stack Engineer at [SCC](https://scc.uz/) based in Uzbekistan. I ship **production smart-city systems**: real-time video analytics, **ANPR / license-plate recognition**, PTZ camera infrastructure, and operator-facing dashboards — end to end, from the GPU detection pipeline to the React/Vue UI the operator actually uses.

My work spans **parking & car-market control**, **market (bozor) monitoring**, **safe-city video streaming**, and **industrial SCADA**. I graduated from **KIUT** (Information Systems) and like turning messy camera streams and sensor data into reliable, observable software.

---

## 🚀 What I Build

- 🅿️ **Parking & ANPR systems** — full parking-control platform on **.NET 8 + React + NVIDIA DeepStream**, real-time plate recognition, slot occupancy and billing
- 🛒 **Market (bozor) monitoring** — computer-vision detection and analytics over market/car-bazaar camera feeds
- 🎛️ **SCC platform** — Smart Control Center: PTZ control, video streaming (RTSP/ONVIF), face anti-spoofing, network/subnet tooling
- 🏭 **Industrial SCADA** — *Uzmetkombinat* operator dashboard (**Vue 3**) with a **.NET 10** backend (PostgreSQL, JWT, voice pipeline, ANPR/ISUP/L3 integrations)
- 🎥 **Camera infrastructure** — Hikvision PTZ systems and **HCNetSDK** integration, RTSP/ONVIF pipelines, safe-city streaming
- 🤖 **Automation** — task/automation tooling (Excel automation, Telegram bots/notifiers)
