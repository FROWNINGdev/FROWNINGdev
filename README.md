## 👨‍💻 About Me

Hi! I'm **Amal Ablakulov** — a Full-Stack Python Engineer at [SCC](https://scc.uz/) based in Uzbekistan. I build production systems at the intersection of **computer vision**, **camera/PTZ infrastructure**, and **industrial monitoring dashboards** — from real-time detection pipelines to operator-facing SCADA UIs.

I graduated from **KIUT** (Information Systems) and enjoy turning camera streams and sensor data into reliable, observable software.

---

## 🚀 What I Build

- 🎯 **Computer Vision & detection** — object/scene detection and real-time video analytics in Python
- 🎥 **Video streaming & camera control** — RTSP/ONVIF pipelines, Hikvision PTZ camera systems and **HCNetSDK** integration
- 🏭 **Industrial SCADA dashboards** — operator monitoring UIs built with **Vue 3** (e.g. the *Uzmetkombinat* project)
- 🧰 **Backends & frontends** — services and apps in **Go**, **TypeScript** and **JavaScript**
- 🤖 **Automation** — task/automation tooling (Excel automation, Telegram bots/notifiers)
